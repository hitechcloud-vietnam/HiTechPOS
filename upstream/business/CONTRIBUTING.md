# Contributing

Use a `codex/` branch by default for implementation work and follow AGENTS.md. Keep commits focused and credit human contributors only.

Run `npm run check`, `npm run format:check`, `npm run build:web` and the relevant browser/device checks before proposing a change. `npm run check:attribution` is required before opening a pull request.

Do not commit credentials, private operational documents, customer data, signing keys or service tokens. Use fictional fixtures. Explain shipped versus sample/proposed behavior in documentation and PR descriptions. Do not enable live credentials or financial actions until their phase gates are met.
