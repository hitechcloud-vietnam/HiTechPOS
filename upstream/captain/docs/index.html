Captain

Order-taking app for restaurant floor staff.

iPhone

Install on this iPhone

Open this page in Safari on the iPhone itself. The button does nothing in Chrome, on a Mac, or on a PC, because only iOS understands it.

This build only installs on registered devices.

It is an ad-hoc build, tied to specific iPhones by their device id. On any other iPhone the install fails with "Unable to Install". That is the build working as intended, not a fault: ask for the device to be added.

After installing, iOS may refuse to open it until the developer is trusted: Settings → General → VPN & Device Management, pick Posnic Innovations Private Limited, then Trust.

Android

Download the APK

Open it on the phone. Android asks permission to install from this source the first time.

Choosing a server

On the shop Wi-Fi, open Server settings (the gear on the sign-in screen) and tap Find server on this Wi-Fi. Otherwise type the shop code, for example azure, tap Test, then Save & Use.
