# HiTechPOS Captain – local changes

Captain (waiter / order-taking app) vendored from https://github.com/Posnic/captain
(AGPL-3.0-only, see `LICENSE`), maintained as **HiTechPOS Captain**. Source stays
under AGPL-3.0; the sign-in screen credits "HiTechPOS · dựa trên Posnic (AGPL-3.0)".

## Changed

| Area | Before | After |
|---|---|---|
| App id (Capacitor `appId`, Android package, iOS bundle) | `com.posnic.captain` | `vn.hitechpos.captain` (`capacitor.config.json`) |
| App name | `Captain` | `HiTechPOS Captain` |
| Java package of `android-templates/*.java` | `com.posnic.captain` | `vn.hitechpos.captain`; `build-apk.js` derives the source folder from `appId` |
| Return-to-app scheme (Android intent filter) | `com.posnic.captain://authorized` | `vn.hitechpos.captain://authorized` (derived from `appId` in `build-apk.js`) |
| Shop code → cloud address | `https://<code>.posnic.io/api` | `https://<code>.hitechpos.vn/api` (`CLOUD_SUFFIX` in `config.js`) |
| Account approval service | `https://www.posnic.com/api/mobile/*` | `https://app.hitechpos.vn/api/mobile/*` (`ACCOUNT_ORIGIN` in `config.js`, used by `assets/common/onboarding.js`, `access.js`; native allow-list in `SecureSessionPlugin.java`, `CaptainPlugins.swift`) |
| Default language | English | Vietnamese (`DEFAULT_LANGUAGE` in `assets/common/i18n.js`; a stored choice still wins) |
| UI strings "Posnic"/"POSNIC"/"Posnic Cloud" | | "HiTechPOS"/"HiTechPOS Cloud" in source, all 30 catalogs (`assets/common/locales/*.json`), `lang-ta.js`, rebuilt `languages.js` |
| Sign-in subtitle | "By Posnic" | "HiTechPOS · based on Posnic (AGPL-3.0)" / vi "HiTechPOS · dựa trên Posnic (AGPL-3.0)" |

| `scripts/device-check.js` defaults | `com.posnic.captain`, `develop.posnic.io` | `vn.hitechpos.captain`, `https://demo.hitechpos.vn/api` |

LAN discovery (port 5555, subnet sweep, `/api/runtime-info`) is unchanged.

### Build-time cloud override

`CLOUD_SUFFIX` and `ACCOUNT_ORIGIN` are the only cloud constants. Build for another
environment with

```sh
HITECHPOS_CLOUD_SUFFIX=.staging.hitechpos.vn \
HITECHPOS_ACCOUNT_ORIGIN=https://app.staging.hitechpos.vn \
npm run build            # or build:apk / build:ipa
```

`scripts/hitechpos-config.js` validates both, rewrites them in `dist/config.js`
(vite plugin) and puts the account host into the native browser allow-list
(`build-apk.js`, `scripts/install-ios-plugins.js`). `npm run dev` serves the
defaults. Test: `tests/hitechpos-cloud.test.js`, `tests/hitechpos-defaults.spec.js`.

### Kept on purpose

- Internal identifiers and storage keys: global `POSNIC`, `posnic.server`,
  `posnic.session`, `posnic.language`, Android keystore alias
  `posnic.captain.session.v1`, iOS keychain service `com.posnic.captain.session.v1`,
  DOM ids `posnic-*`, events `posnic:*`. Renaming them would wipe data on
  installed phones and is not visible to users.
- Release signing path `~/.posnic/captain-signing/` (`android-templates/release-signing.gradle`,
  `.github/workflows/release.yml`) and env `POSNIC_VERSION`.
- `LICENSE`, `.github/SECURITY.md` / `CODE_OF_CONDUCT.md` (Posnic project contacts),
  upstream history in `docs/*.json` and code comments.
- Protocol: Captain still asks the account service for `application: "captain"`.
